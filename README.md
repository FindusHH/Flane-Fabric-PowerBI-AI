# Power BI & Fabric AI Advanced

An advanced seminar agenda and tutorial collection covering AI-assisted development, analytics, and application scenarios across Microsoft Power BI and Microsoft Fabric.

The course is organized into 13 chapters. Each chapter has its own Markdown file with section links, learning resources, and practical exercises where available.

## Course agenda

Start with the [complete agenda](./00_Agenda%20with%20Tutorials.md) to browse all chapters and open their materials.

The chapters cover:

1. Copilot in Power BI: Reports and DAX
2. Copilot in Fabric: Data Transformation, Spark, and SQL
3. Vibe Coding with Power BI and Visual Studio Code
4. GenAI-based Report Commenting
5. Fabric AI Functions and Azure OpenAI
6. Fabric IQ and Ontology
7. Fabric Data Agents
8. Fabric Operations Agents
9. Semantic Link and Semantic Model Analysis
10. Fabric Apps with Rayfin
11. Retrieval-Augmented Generation (RAG)
12. Customer Use Cases and Proofs of Concept
13. General Fabric Samples

## How to use this repository

- Open the agenda and select a chapter.
- Use the chapter's contents list to navigate its sections.
- Follow the linked Microsoft Learn materials and other resources.
- ⭐ marks hands-on tutorials, labs, and quickstarts.

## Prerequisites

This course is intended for learners with experience in Power BI and Microsoft Fabric. Requirements vary by chapter and exercise. Some Copilot activities require a supported capacity, appropriate permissions, and tenant or administrator settings. Check the prerequisites in the relevant chapter and linked resources before starting.
