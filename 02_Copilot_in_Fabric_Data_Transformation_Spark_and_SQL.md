**Teaching note:** Begin with an overview of Copilot across Fabric, then explore data preparation, notebook-based Spark analysis, and SQL analysis in a warehouse. ## 2.1 Copilot in Fabric Overview

## 2.2 Data Preparation and Data Factory Pipelines

- ⭐ **Copilot in Dataflow Gen2** — [Work smarter with Copilot in Microsoft Fabric Dataflow Gen2](https://microsoftlearning.github.io/mslearn-fabric/Instructions/Labs/22a-copilot-fabric-dataflow-gen2.html) — **Hands-on lab (approximately 30 minutes):** clean retail store data, parse XML, create categorical groups, and set data types using natural language prompts. Publish the results to a lakehouse. Requires paid Fabric capacity; trial capacity is not supported.

- **Copilot in Data Factory pipelines** — [Get started with Copilot in Fabric in the Data Factory workload](https://learn.microsoft.com/en-us/fabric/data-factory/copilot-fabric-data-factory-get-started) — **Getting-started guide:** covers Copilot in the Data Factory workload, including pipelines; distinct from the Dataflow Gen2 lab.

## 2.3 Spark Analysis in Fabric Notebooks

- **Copilot in Data Engineering and Data Science** — [Overview of Copilot for Data Engineering and Data Science](https://learn.microsoft.com/en-us/fabric/data-engineering/copilot-notebooks-overview) · [Use the Copilot chat pane in notebooks](https://learn.microsoft.com/en-us/fabric/data-engineering/copilot-notebooks-chat-pane) — **Overview and feature guide:** introduce notebook Copilot and its chat pane.

- ⭐ **Copilot in Fabric notebooks** — [Analyze data with Apache Spark and Copilot in Microsoft Fabric notebooks](https://microsoftlearning.github.io/mslearn-fabric/Instructions/Labs/22b-copilot-fabric-notebooks.html) — **Hands-on lab (approximately 30 minutes):** generate Spark code to clean, filter, and reshape population data, save it to a lakehouse, and visualize the results. Requires paid Fabric capacity; trial capacity is not supported.

## 2.4 SQL Analysis in Fabric Data Warehouse

- **Data Warehouse Copilot chat pane** — [How to use the Copilot chat pane in Fabric Data Warehouse](https://learn.microsoft.com/en-us/fabric/data-warehouse/copilot-chat-pane) — **Feature guide:** use the warehouse Copilot chat experience.

- ⭐ **Copilot in Fabric Data Warehouse** — [Use Copilot in Microsoft Fabric data warehouse](https://microsoftlearning.github.io/mslearn-fabric/Instructions/Labs/22c-copilot-fabric-data-warehouse.html) — **Hands-on lab (approximately 30 minutes):** use retail sales data to generate and refine SQL queries, fix syntax errors, and create reusable views with Copilot. Requires paid Fabric capacity; trial capacity is not supported.

## 2.5 Optional: Real-Time Intelligence
